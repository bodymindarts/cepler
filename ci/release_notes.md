- concourse `in`: fix "object not found" failure during `prepare` for envs that propagate from a previous env with old `from_commit`s. The shallow clone (default `depth: 50` since v0.7.19) didn't include those commits, and `checkout_file_from` had no deepen-on-demand fallback. Now `Workspace::prepare` reads the propagated `from_commit`s straight from the previous env's state file and batch-fetches them by OID with `depth=1` in a single round-trip before the per-file checkout loop — no progressive-depth guessing. Requires the server to advertise `tip-oid` or `reachable-oid` (GitHub: yes by default; self-hosted: `uploadpack.allow{Any,Reachable}Sha1InWant=true`).
