- concourse `in` / CLI `--clone-dir`: replace libgit2's `RepoBuilder::clone` with a `git clone --no-checkout` subprocess. libgit2's pack indexing is 5-10x slower than git's (long-standing limitation tracked in libgit2 issues [#4674](https://github.com/libgit2/libgit2/issues/4674), [#3920](https://github.com/libgit2/libgit2/issues/3920), [#2836](https://github.com/libgit2/libgit2/issues/2836); root cause is mmap/munmap inefficiency in `git_mwindow_free_all_locked`). On the volcano-qa-lana-bank state branch this drops the clone phase from ~64s to ~6s (measured against v0.7.21's `[cepler-perf]` lines).
- the rest of cepler keeps using libgit2 via `Repository::open` — only the initial fetch is shelled out. Requires the `git` CLI on PATH. The concourse resource image already ships it; standalone CLI users almost certainly have it. SSH auth is handled by writing the source's `private_key` to a tempfile with 0600 perms and pointing `GIT_SSH_COMMAND -i` at it; the tempfile is removed on drop (RAII) so a panic between write and clone can't leak the key.
